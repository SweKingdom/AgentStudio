# Task tracker (AgentStudio demo)

A tiny JSON API for tasks, with no dependencies. AgentStudio's agents extend it with the stories in
[`../requirements.md`](../requirements.md).

```bash
npm test        # node --test
npm run lint    # no TODO or console.log in src/
npm run build   # syntax check
npm start       # http://localhost:3000/api/tasks
```
